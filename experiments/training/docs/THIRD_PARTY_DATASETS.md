# Third-party dataset provenance

The local names `CHVG4` and `SHEL4` describe cleaned four-class derivatives, not
official upstream release names. The local `Pictor-yolo` contribution consists
only of adjudicated no-person negatives.

| Local derivative | Upstream source | Link |
|---|---|---|
| CHVG4 | CHVG Dataset | https://figshare.com/articles/dataset/chvg_dataset/19625166 |
| SHEL4 | SHEL5K | https://data.mendeley.com/datasets/9rcv8mm682 |
| SH17 | SH17 Dataset | https://github.com/ahmadmughees/SH17dataset |
| Pictor-yolo negatives | Pictor-PPE / Pictor-v3 family | https://github.com/ciber-lab/pictor-ppe |

Do not infer redistribution permission from inclusion in this table. Review the
current license and attribution terms at each source before publishing images,
annotations, derivatives, or trained weights.
