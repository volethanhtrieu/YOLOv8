# Licensing decision required

Ultralytics currently offers its YOLO framework and models under AGPL-3.0 or an
applicable commercial/Enterprise license. Choose the repository license only
after confirming which Ultralytics terms apply to this project and intended use.

The datasets have independent licenses and attribution requirements. A software
license for this repository does not grant permission to redistribute dataset
images, labels, derived annotations, or trained model files.

Recommended public-repository process:

1. Keep datasets, credentials, model binaries, and private paths out of Git.
2. Confirm AGPL-3.0 compatibility with all team members.
3. Confirm all upstream dataset terms.
4. Add the complete team-approved `LICENSE` text at repository root.
5. Add all contributor details to `CITATION.cff.example`, then rename it to
   `CITATION.cff`.
6. Review dataset and model-weight redistribution separately from source code.
